About ESOBuild.com

ESOBuild.com is an up-to-date report of "meta" Elder Scrolls Online trial builds, automatically curated from the top 12 ranked ESO Logs reports for each trial. It lets you explore builds used by top-performing players for each trial and boss encounter. In short, it answers the question: "what is meta right now?"

ESOBuild is built by @brainsnorkel(my ESO PC NA handle and GitHub account name). Let me know in game mail if you find this site useful. If you find a problem, or have suggestions,open an issue in GitHub.

How It Works

To this tool, a "build" is a unique combination of subclasses (skill lines), and two "5-piece" gear sets with 4 or more pieces of each equipped. Yes, this is a simplifying assumption.

ESO Build scans the top-ranked trial reports that have logs using the ESO Logs API. Player gear and subclass information is extracted from leaderboard report boss fights to identify the most frequently-seen combinations in top reports. Arguably, this is "the meta" for each fight. This approach might not end up selecting the highest DPS if they have a unique build. ESOBuild.com is way better at finding DPS builds than healers and tanks. There are lower numbers of healers and tanks than dps, and the large number of viable subclass options makes it hard to find common tank and healer builds from this small sample. If no healers or tanks are found that match the criteria, ESOBuild.com will find one or two to display in the highest ranked report with that has players with that role.

Build Requirements

A build is considered "common" and included in our report if it appears:

  • 5 or more times for DPS builds
  • 3 or more times for healer and tank builds

This ensures we only show builds that have been seen used by multiple players for that fight across the 10 top-ranked reports.

Data Source

All build data comes from ESO Logs, the preeminent encounterlog analysis site for Elder Scrolls Online. If you are uploading encounter logs to esologs.com, I recommend uploading with ESO Log Tool by sheumais. It provides much better upload speed than the esologs.com client, and many helpful features like script enumeration for scribed abilities and improved stack tracking for many sets and buffs/debuffs.
